# 弹幕互动墙

扫码即发的现场弹幕大屏。观众用微信扫大屏上的二维码，输入一句话，内容会实时飘过大屏，不需要登录，也不要求手机和大屏连同一个网络。

大屏右下角有一个「停止 · 生成词云」按钮，点击后封场并停收新弹幕，把本场所有弹幕整理成按词频排版的整页词云。

## 功能

- **扫码发送**：大屏二维码按当前访问域名自动生成，公网、局域网访问都会指向正确的发送页
- **实时上墙**：WebSocket 推送，大屏按屏幕高度自动分行，每条弹幕占用最早空闲的轨道，不会叠字
- **免登录**：手机端打开即发，40 字上限，有常用短语快填
- **敏感词拦截**：命中 [filter.txt](filter.txt) 的词直接拒绝发送，正文和署名都会检查，空格、标点、全角写法也能识别
- **清屏**：管理台一键清空大屏与计数，二次点击确认，防止误触
- **停止与词云**：停止后服务端封场，新弹幕不再接收，手机端提示「本场弹幕已结束」，大屏转为词云
- **管理台**：查看累计上墙、拦截次数、词条数、在线连接数

## 快速开始

要求 Node.js 18+。跨网络访问需要 [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)。

```bash
npm install
./start.sh
```

`start.sh` 会同时拉起本地服务和公网隧道，并打印大屏地址、管理台地址（含密钥）。

只在本机或局域网用，不需要公网隧道：

```bash
npm start
```

打开 `http://localhost:3000` 是大屏，`http://localhost:3000/send` 是手机发送页。同一 WiFi 下用本机局域网 IP 访问，二维码同样可用。

## 使用流程

1. 在大屏所在设备打开打印出来的大屏地址，投影或投屏
2. 观众扫码进入发送页，输入内容后点发送
3. 弹幕实时飘过大屏
4. 活动结束点右下角「停止 · 生成词云」，大屏切换为词云
5. 需要继续收弹幕时点「返回实时弹幕」

## 配置

| 项目 | 位置 | 说明 |
| --- | --- | --- |
| 端口 | 环境变量 `PORT` | 默认 `3000` |
| 敏感词 | [filter.txt](filter.txt) | 一行一个词，`#` 开头为注释；保存后约 1 秒生效，无需重启 |
| 管理密钥 | `.admin-key` / 环境变量 `ADMIN_KEY` | 首次启动自动生成并写入 `.admin-key`；环境变量优先 |
| 发送限流 | `server.js` 中 `SEND_LIMIT` | 默认每个 IP 10 秒 30 条，适配现场共用 WiFi 的场景 |
| 字数上限 | `server.js` 中 `MAX_LEN` | 默认 40 字 |

管理台地址启动时打印在终端，形如：

```
http://localhost:3000/admin?key=<你的密钥>
```

也可以把 `localhost:3000` 换成公网域名使用。密钥错误会直接返回 403，页面源码里不会带出密钥。

## 目录结构

```
server.js            HTTP 服务、WebSocket 广播、二维码、敏感词、封场状态
public/screen.html   大屏：弹幕轨道、二维码、停止键与词云
public/send.html     手机发送页
views/admin.html     管理台：统计与清屏
filter.txt           敏感词表
start.sh             一键启动服务 + 公网隧道
```

## 接口

| 方法与路径 | 说明 |
| --- | --- |
| `POST /api/send` | 发送弹幕，JSON：`{ "text": "...", "nick": "..." }` |
| `GET /api/info` | 当前总数、封场状态与最近弹幕 |
| `GET /api/cloud` | 本场全部弹幕原文，用于生成词云 |
| `GET /api/qr.png?url=` | 生成二维码图片 |
| `POST /api/close` | 停止并封场，广播给所有大屏 |
| `POST /api/open` | 恢复接收弹幕 |
| `GET /admin?key=` | 管理台页面 |
| `GET /api/stats` | 统计数据，需要 `x-admin-key` 头或 `key` 参数 |
| `POST /api/clear` | 清屏并解除封场，需要管理密钥 |
| `WS /ws` | 实时推送：`danmaku`、`clear`、`closed`、`open` |

## 实现说明

- 实时链路使用 WebSocket 而不是 SSE。Cloudflare 快速隧道会缓冲 SSE 首包，导致公网收不到数据；WebSocket 在隧道下正常
- 弹幕轨道按 `busyUntil` 时间分配，每条弹幕只创建一个 DOM 节点，动画结束后立刻移除，长时间运行不会累积
- 词云分词用浏览器原生 `Intl.Segmenter`，中文可直接切词；排版采用网格起点 + 螺旋寻位 + 矩形碰撞检测，字号按词频对数映射
- 弹幕数据只存在内存中：服务重启、清屏、封场重置后会清空，不落库

## 现场注意事项

- 免费版 Cloudflare 快速隧道每次重启都会换域名，二维码会跟着变；需要固定地址请改用带域名的 named tunnel，或把服务部署到云主机
- 隧道依赖本机进程：电脑睡眠、断网、关闭终端都会导致公网地址不可用
- 隧道默认走 HTTP/2（TCP），在不稳定网络下比 QUIC 更容易保持连接
- 停止键在大屏页面上是公开的，拿到大屏网址的人也能点击；现场由自己控制大屏即可
- 敏感词表只是兜底，公开活动仍建议安排人盯屏
